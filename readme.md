# JobFinder Global 🌍

JobFinder Global is a web application that helps users search for job opportunities worldwide.

The application uses the Adzuna Jobs API to retrieve job listings and provides users with search, filtering, sorting, and saving features.

---

# Features

## Job Search
- Search jobs by keyword
- Search jobs by location
- Browse popular global locations

## Job Filtering
- Filter jobs by category:
  - Technology
  - Engineering
  - Healthcare
  - Finance
  - Marketing

## Job Management
- View job details
- Save jobs locally
- Apply through job links

## Reliability Features
- External API integration
- API error handling
- Backup job database when API data is unavailable
